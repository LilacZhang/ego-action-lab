# v0.1.0 发布验证

这份记录描述发布前的工程验证，不是模型精度或机制研究的结果报告。

## 本地检查

环境：Apple Silicon、Python 3.12.14、MLX 0.32.4；精确依赖见 `requirements-tested.txt`。

| 检查 | 结果 |
| --- | --- |
| 独立环境安装 | 通过；没有依赖原 EGO 项目目录 |
| Ruff 静态检查与格式检查 | 通过 |
| 自动测试 | 9 项通过，覆盖数据流程/完整性、会话与重复数据拒绝、掩码/归一化、坐标变换、指标边界、合成标签、Flow Matching 和检查点 |
| 合成 HDF5/视频 → 数据准备 → inspect | 通过，train/validation 各 4 个窗口 |
| 实际 130,822,704 参数模型训练 | 合成数据上完成 2 次优化更新 |
| 完整模型暂停/恢复 | 更新 1 后保存，恢复完成更新 2；与连续运行 2 次更新的 290 个参数数组逐位一致 |
| 检查点评测 | 通过，4 个验证窗口，JSON 中保留合成数据标识 |
| 实际 DINOv3 权重加载/特征缓存 | 通过，在合成视频上运行当前帧编码；没有发布或下载到仓库中 |
| Wheel 与源码分发包 | 构建及内容检查通过；独立 CPU 环境从 wheel 安装后运行 demo/inspect 通过 |

## 自动 CI

GitHub Actions 配置运行 Linux/Python 3.10 与 3.12 的 CPU 流程、静态检查、合成示例及构建。MLX 测试在没有 MLX 的环境中显式跳过，不能把 CPU CI 通过理解为 GPU 训练通过。

## 尚未验证/不作声明

本次没有在公开完整数据集上重新训练至收敛，没有评估机器人闭环迁移，也没有完成研究路线中的机制消融。合成样例只用于代码验证，不能作为模型优于基线的研究证据。跨设备逐位一致、CUDA 训练以及百万窗口规模的准备尚未验证。
