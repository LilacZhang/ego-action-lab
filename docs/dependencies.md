# 依赖与资源

| 组件 | 用途 | 平台 |
| --- | --- | --- |
| Python 3.10–3.12 | CLI / 工具 | macOS、Linux |
| NumPy 2.x | 窗口、几何、指标 | CPU |
| h5py 3.x | EgoDex HDF5 读取 | CPU |
| PyAV 14–16 | 视频解码、原生 PTS、合成视频 | CPU；常见平台 wheel 已含 FFmpeg 库 |
| Pillow 10–11 | 固定尺寸图像预处理 | CPU |
| MLX 0.32.4（可选 extra） | 视觉编码、动作模型、训练和采样 | Apple Silicon macOS |
| pytest / Ruff / build（dev extra） | 测试、格式检查、发行包构建 | 开发环境 |

依赖范围定义在 `pyproject.toml`。精确的发布测试版本见 `requirements-tested.txt`；该文件用于重建已测环境，不意味着其他平台可使用 MLX。本次安装的 MLX 0.32.4 wheel 要求 macOS 26 或以上；旧版系统需要先解决运行时兼容性，不能假定此固定版本可直接安装。

131M 模型参数本身约 0.52 GB（FP32）。梯度、AdamW 状态、激活、编译缓存和评测采样会占用额外内存；训练应预留数 GB 以上统一内存及数 GB 检查点磁盘空间。显存压力较大时降低 batch_size，并在评测时减少 samples。首版尚无梯度累积、混合精度训练或多设备训练。

大规模准备时，特征缓存大小约为每个独立当前帧 196×384×2 字节，不含文件头。窗口及特征目前在准备时累积于内存，应先用小子集验证。

不需要 W&B、访问令牌、云端实验平台或运行原项目环境。数据与编码器权重需使用者单独获取；不存在隐式下载。
